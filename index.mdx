Brian2 is a clock-driven simulator for spiking neural networks written in Python. Whether you are modeling a single leaky integrate-and-fire neuron or a large-scale cortical network with plastic synapses, Brian lets you express your model as equations and takes care of the rest — from numerical integration to code generation.

## Why Brian2?

Brian2 is designed to save the time of scientists, not just processors. Its equation-based model definition means you write neural models the same way they appear in papers — no translation into simulator-specific abstractions required.

## Get Started in 3 Steps

<Steps>
  <Step title="Install Brian2">
    Install Brian2 into a Python environment using conda or pip:
    ```bash
    conda install -c conda-forge brian2
    # or
    pip install brian2
    ```
  </Step>
  <Step title="Write your first simulation">
    Define a leaky integrate-and-fire network and run it:
    ```python
    from brian2 import *

    tau = 10*ms
    G = NeuronGroup(100, 'dv/dt = -v/tau : volt',
                    threshold='v > -50*mV', reset='v = -70*mV')
    G.v = -70*mV

    M = SpikeMonitor(G)
    run(100*ms)
    print(f'Total spikes: {M.num_spikes}')
    ```
  </Step>
  <Step title="Explore further">
    Browse the [User Guide](/user/models-and-neuron-groups) to learn about synapses, recording, and performance optimizations — or jump to the [Examples](/examples/overview) to see complete published network models.
  </Step>
</Steps>

<Note>
  Brian2 requires Python ≥ 3.12 and NumPy ≥ 2.0. See the [installation page](/installation) for full dependency details and platform-specific instructions.
</Note>
